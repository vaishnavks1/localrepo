## 2025-07-31 - Static HTML Performance Optimization
**Learning:** For extremely minimal, single-file static web applications without a build pipeline or backend server, the most high-impact performance optimizations focus on browser-level document parsing and network waste elimination. Adding a `<!DOCTYPE html>` triggers Standards Mode, ensuring optimized rendering paths. Specifying early `<meta charset="UTF-8">` prevents character-encoding sniffing pauses. Additionally, declaring a data-URI favicon `<link rel="icon" href="data:,">` prevents automatic and wasteful network roundtrips to find `/favicon.ico` which would result in a costly `404 Not Found` response.
**Action:** When working on similar static web configurations, immediately audit the document structure for Standards Mode, charset definition, and favicon references to ensure rapid and correct first-contentful paint without redundant network activity.
