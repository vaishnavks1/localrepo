# Bolt's Journal - Critical Learnings

## 2025-07-11 - Initial Codebase Assessment

**Action:** Use Python/Playwright for verification since traditional JS-based testing tools (Vitest/Jest) aren't set up. Focus on fundamental web performance optimizations (Standards Mode, Resource Hints, 404 prevention).
